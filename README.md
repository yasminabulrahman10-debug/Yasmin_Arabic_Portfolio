# معرض أعمال ياسمين عبدالرحمن هرين

موقع شخصي عربي باتجاه RTL، مبني باستخدام HTML وCSS وJavaScript، مع الحفاظ على التصميم الوردي والتجاوب مع الجوال.

## تشغيل الموقع
1. فكّي ضغط الملف ZIP.
2. افتحي مجلد `Yasmin_Arabic_Portfolio`.
3. افتحي `index.html` في المتصفح. للمعاينة أثناء التعديل، يمكنك استخدام إضافة Live Server في VS Code.

## خريطة الملفات
- `index.html`: محتوى الموقع وأقسامه وبطاقات المشاريع والنصوص والصور المرتبطة بها.
- `css/portfolio.css`: ألوان الموقع وتنسيقاته وتجاوبه مع أحجام الشاشات. متغيرات الألوان الأساسية في بداية الملف داخل `:root`.
- `js/script.js`: تفاعلات قائمة الجوال والوضع الداكن وتصفية المشاريع وأيقونات عرض المواقع المنشورة.
- `images/`: الصور الشخصية وصور المشاريع والشهادات.
- `files/Yasmin_CV.pdf`: ملف السيرة الذاتية.

## إضافة رابط عرض موقع إلى صورة المشروع
1. افتحي `js/script.js`.
2. ابحثي عن `const projectDemoLinks`.
3. أمام اسم المشروع المطلوب، ضعي رابط الموقع المنشور بين علامتي الاقتباس.

مثال:
```js
const projectDemoLinks = {
  "ABC-WORLD | عالم الحروف": "https://example.com",
  "موقع زينة السيارات": "",
  "SHENA | متجر شينا": ""
};
```

استبدلي `https://example.com` بالرابط الحقيقي. إذا تركتِ الرابط فارغًا `""` فلن تظهر أيقونة «عرض الموقع» على صورة ذلك المشروع. لا تضعي رابط مستودع GitHub هنا؛ المطلوب رابط الموقع المنشور نفسه.

**مهم:** يجب أن يطابق اسم المشروع في هذا الكائن عنوانه المكتوب داخل بطاقة المشروع في `index.html` تمامًا، بما في ذلك المسافات والرموز.

## تعديل محتوى المشروع
افتحي `index.html` وابحثي عن عنوان المشروع، ثم عدّلي العنوان أو الوصف أو التقنيات أو حالة المشروع. حالات المشاريع:
- `completed`: مكتمل.
- `progress`: قيد التطوير.
- `planned`: مخطط.

## وصف مشروع التخرج
اختُصر الوصف إلى ملخص هدف التطبيق ووظائفه، وأزيلت فقرة أدوات التطوير الطويلة وشارات Android وSQL Server 2019 وPHP من هذا القسم.

## قبل النشر
- أضيفي فقط روابط المواقع التي تعمل فعلًا.
- تأكدي من أن وصف كل مشروع وحالته يعكسان العمل المنفذ.
- استبدلي الصور التوضيحية بلقطات شاشة حقيقية عند الحاجة.
- تحققي من بيانات التواصل وملف السيرة الذاتية.
